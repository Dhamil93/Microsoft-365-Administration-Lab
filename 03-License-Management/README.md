\# Microsoft 365 License Management



\## Objective



Practice assigning, removing, and reassigning Microsoft 365 licenses to user accounts.



\## Environment



\- Microsoft 365 Admin Center

\- Microsoft 365 Business Premium



\## Test User



John Admin  

Department: IT  

Job Title: IT Support Administrator



\## Tasks Completed



\- Reviewed the user's assigned Microsoft 365 license

\- Reviewed Microsoft 365 applications and services

\- Removed a Microsoft 365 Business Premium license

\- Verified license availability after removal

\- Reassigned the Microsoft 365 Business Premium license

\- Verified successful license assignment



\## Scenario



This exercise simulated license management during employee onboarding, offboarding, and account administration.



When a user no longer requires Microsoft 365 services, an administrator can reclaim the assigned license so that it can be assigned to another user.



\## Skills Demonstrated



\- Microsoft 365 license administration

\- User license assignment

\- License reclamation

\- License reassignment

\- Microsoft 365 Admin Center

\- User lifecycle management
