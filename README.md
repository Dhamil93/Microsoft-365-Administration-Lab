\# Microsoft 365 Administration Lab



\## Project Overview



This project demonstrates hands-on Microsoft 365 administration experience using a Microsoft 365 Business Premium lab environment.



The lab was designed to simulate common tasks performed by IT Support, Help Desk, and Microsoft 365 administrators, including user administration, licensing, group management, Exchange Online, identity security, administrative roles, and troubleshooting.

\* Microsoft 365 Business Premium

\* Microsoft 365 Admin Center

\* Microsoft Entra ID

\* Exchange Online

\* Exchange Admin Center

\* Microsoft Outlook

\* Microsoft Authenticator

\* Conditional Access

\* PowerShell

\* Git

\* GitHub

\## Security Practices



Security best practices were considered throughout the project.



\* No passwords were stored in the repository.

\* MFA secrets and QR codes were excluded.

\* Administrative permissions were limited where possible.

\* Conditional Access was initially tested using Report-only mode.

\* Elevated administrative roles were removed after testing.

\* Shared mailbox access used delegation instead of credential sharing.

\* Test accounts were used for troubleshooting exercises.
