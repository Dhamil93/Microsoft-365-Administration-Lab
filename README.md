\# Microsoft 365 Administration Lab



\## Overview



This project demonstrates hands-on Microsoft 365 administration skills using a lab environment.



\## Skills Demonstrated



\- Microsoft 365 Admin Center

\- Microsoft Entra ID

\- User account creation and management

\- License management

\- Microsoft 365 Groups

\- Exchange Online administration

\- Password resets

\- Account blocking and unblocking

\- Multi-Factor Authentication

\- Administrative role management

\- Basic Microsoft 365 troubleshooting



\## Lab Sections



1\. Tenant Setup

2\. User Management

3\. License Management

4\. Groups

5\. Exchange Online

6\. MFA and Security

7\. Admin Roles

8\. Troubleshooting
